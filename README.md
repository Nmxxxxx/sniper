# pumpfun-sniper

Учебный бот для pump.fun (Solana) с веб-панелью. Работает только в режиме **paper trading**:
слушает новые токены через PumpPortal WebSocket, виртуально покупает по фильтрам
и закрывает позиции по тейк-профиту, стоп-лоссу или таймеру. Реальных сделок нет.

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env             # по желанию
python bot.py
```

Откроется панель http://127.0.0.1:8000. Бот стартует остановленным: нажмите «Запустить».

## Что есть в панели

- **Обзор**: PnL, доля прибыльных сделок, лучшая и худшая сделка, график прибыли, разбивка по причинам выхода.
- **Позиции**: открытые виртуальные сделки в реальном времени.
- **Сделки**: история с фильтром по причине выхода.
- **Обучение**: состояние модели, проверка «помогает ли она» на новых данных и таблица выученных признаков.
- **Настройки**: все параметры стратегии меняются на лету.
- **Лог**: события бота.

Закрытые сделки сохраняются в `trades.csv`, статистика подхватывается после перезапуска.

## Источник данных

Нужны два потока: создание токенов и сделки по ним (без сделок нет цен, а значит нет ни paper-торговли, ни обучения). Бесплатный доступ PumpPortal отдаёт только создание токенов, поэтому есть два варианта.

**Бесплатно, из блокчейна (рекомендуется).** Бот сам читает логи программы pump.fun через Solana RPC и разбирает события. Нужен WebSocket-адрес RPC-провайдера (например, Helius, QuickNode, Chainstack) в `.env`:

```
SOLANA_WS_URL=wss://mainnet.helius-rpc.com/?api-key=ВАШ_КЛЮЧ
```

Поток данных большой. Если провайдер ограничивает бесплатный тариф, причина будет видна во вкладке «Лог». На «Обзоре» карточка «Транзакций / с событиями» показывает, находит ли бот в транзакциях события pump.fun.

**Платно, через PumpPortal.** API-ключ и привязанный кошелёк минимум с 0.02 SOL, ключ в `.env` как `PUMPPORTAL_API_KEY=...`. Условия и списания смотрите на pumpportal.fun. Используется, только если `SOLANA_WS_URL` не задан.

Адрес с ключом и сам ключ нельзя публиковать и коммитить. Бот не показывает их в панели и вырезает из сообщений об ошибках.

## Как работает обучение

1. Новый токен проходит базовые фильтры и попадает в **окно наблюдения** (по умолчанию 5 секунд). Бот входит уже по цене после окна, как в реальности.
2. За окно собираются признаки: покупка создателя, число уникальных покупателей, продажи, продал ли создатель, объём, рост market cap.
3. Первые N сделок (по умолчанию 30) идут «в прогрев»: бот берёт всё подряд и копит данные.
4. Дальше модель считает ожидаемый результат по прошлым сделкам и входит, только если он выше порога. Часть входов («пробные», 15%) делается вопреки модели, чтобы она могла проверять себя.
5. Создатели, чьи токены дважды принесли убыток, попадают в чёрный список.
6. Все признаки сохраняются в `trades.csv`, обучение переживает перезапуск.

Вкладка «Обучение» показывает честную проверку: для каждой сделки модель знает только прошлое, и сравниваются результаты «взятых» и «пропущенных» входов. Если взятые не лучше пропущенных, модель не помогает, и верить ей не нужно.

## ИИ-оценка токенов

Если в `.env` указан `DEEPSEEK_API_KEY`, то для каждого нового токена, прошедшего базовые фильтры, бот параллельно с окном наблюдения просит модель `deepseek-flash` оценить его: риск скама (0–10) и «хайп» мема (0–10). Оценки становятся признаками модели обучения, а вкладка «Обучение» показывает, дают ли они что-то на практике. Не успел ответ к концу окна, токен оценивается без ИИ.

- Названия моделей DeepSeek меняются: старые `deepseek-chat` и `deepseek-reasoner` отключены с 24 июля 2026. Нужное имя можно задать через `DEEPSEEK_MODEL` в `.env`.
- Название и описание токена пишет его создатель, поэтому они передаются модели как недоверенные данные, а её ответ ограничен двумя числами и короткой причиной.
- Метаданные токена скачиваются только с фиксированного IPFS-шлюза по CID. Адреса из токена бот не открывает.
- Расходы ограничивает лимит вызовов в час (по умолчанию 300). Реальный расход токенов и примерная стоимость видны в панели.
- Жёсткая блокировка по риску ИИ выключена по умолчанию: пока нет данных, что оценка полезна, она только лишит модель обучающих примеров.
- DeepSeek получает только название, тикер, описание и признаки соцсетей токена. Ключи и кошельки не передаются.

## Безопасность

- Панель слушает только `127.0.0.1` и проверяет заголовок Host и тип запросов.
- Не коммитьте приватные ключи. `.gitignore` закрывает `.env` и типовые файлы кошельков.
- Paper-результаты оптимистичнее реальных: не учитываются проскальзывание, задержка и конкуренция с другими ботами.
- Это не финансовый совет.
